# KYC Watch — Bank Al Etihad

A full-stack KYC (Know Your Customer) compliance monitoring system.

## Quick Start

```bash
npm install
npm run dev
```

- Frontend: http://localhost:3000  
- API: http://localhost:5000/api

## Tech Stack
- **Frontend**: React 18, Vite, Tailwind CSS, Recharts, Lucide React
- **Backend**: Express.js, NeDB (embedded NoSQL)
- **Design**: Bank Al Etihad brand palette (#EA8923, #1B2B4B)

## Features
- Customer KYC management (add, edit, view, delete)
- Real-time alert system (expiry, PEP, sanction hits)
- Watchlist screening engine
- Compliance reports with charts
- Document upload and management
- Configurable settings
